### À propos

Je construis surtout des choses qui tournent en continu : serveurs, bots, mods et infrastructure auto-hébergée. J'aime comprendre la stack de bout en bout, du Dockerfile jusqu'au reverse proxy.

- Homelab auto-hébergé sous Fedora Server, stack Docker complète
- Développement de mods et plugins Minecraft
- Backend Go et Java
